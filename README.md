# Gong Fu Cha Android Timer

## How to download the Android APK
1. Click the **Actions** tab at the top of this GitHub repository.
2. Select the latest **Build Android APK** workflow run.
3. Scroll down to **Artifacts** and download **GongFuCha-Android-APK**.
4. Unzip it and install `app-debug.apk` on your Android phone.
